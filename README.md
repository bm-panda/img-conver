# 🖼️ 图片格式转换

一键将图片转换为 PNG / JPEG / WEBP / BMP / GIF / ICO / TIFF 等 200+ 种格式，基于 ImageMagick 引擎，支持批量处理。

---

## 📖 简介

本工具提供一个简洁的图形配置界面，让您轻松配置转换参数。配置完成后，在文件资源管理器中选中图片文件，右键即可一键完成格式转换。

### ✨ 核心特性

- **200+ 格式支持**：基于 ImageMagick 引擎，支持 PNG、JPEG、WEBP、AVIF、HEIC、TIFF 等 200+ 种格式互转
- **右键菜单集成**：配置一次，永久生效。选中图片 → 右键 → 一键转换
- **批量处理**：支持同时选中多张图片批量转换
- **自定义输出目录**：可指定输出位置，留空则保存到原图所在目录
- **质量可调**：图片质量 0-100 自由调节（适用于 JPG/WEBP 等有损格式）
- **智能边缘处理**：自动处理 JPEG 透明通道等特殊情况
- **后台执行**：转换任务在后台运行，界面不会卡顿

## 🚀 启动方式

安装到不忙脚本盒子后，可通过以下方式启动：

| 启动方式     | 说明                           |
| -------- | ---------------------------- |
| 🖱️ 右键菜单 | 选中图片 → 右键 → **「图片格式转换」**     |
| ⌨️ 快捷键   | 在盒子热键管理页面设置快捷键，选中图片后按下即触发    |
| ▶️ 手动运行  | 打开盒子 → 脚本管理 → 点击「运行」按钮       |
| ⚙️ 独立运行  | 直接运行 `main.py` 可打开配置界面（不带参数） |

## 📦 安装方法

### 方式一（推荐）：通过不忙脚本盒子安装

1. 下载并安装 [不忙脚本盒子](https://www.bm-box.cn)
2. 打开不忙脚本盒子 → **脚本市场** → 搜索 **「图片格式转换」**
3. 点击「安装」→ 盒子自动下载脚本并配置好运行环境 ✅

> 盒子会自动为脚本配置环境、自动下载ImageMagick并配置环境变量，**全程无需手动干预**, 安装好即可直接使用。

### 方式二：手动运行（高级用户）

```bash
# 1. 安装 ImageMagick（magick 命令需在 PATH 中可用）
# https://imagemagick.org/script/download.php
# 2. 配置python环境
uv venv
uv sync
# 3. 启动脚本
python main.py                # 启动配置界面（无参数）
python main.py <参数JSON路径>  # 带参数启动（用于右键调用）
```
