# 图片格式转换脚本

一键将图片转换为 PNG / JPEG / WEBP / BMP / GIF / ICO / TIFF 等 200+ 种格式，基于 ImageMagick 引擎，支持批量处理。

---

## 📖 简介

本工具提供一个简洁的图形配置界面，让您轻松配置转换参数。配置完成后，在文件资源管理器中选中图片文件，右键即可一键完成格式转换。

### ✨ 核心特性

- **200+ 格式支持**：基于 ImageMagick 引擎，支持 PNG、JPEG、WEBP、AVIF、HEIC、TIFF 等 200+ 种格式互转
- **右键菜单集成**：配置一次，永久生效。选中图片 → 右键 → 一键转换
- **批量处理**：支持同时选中多张图片批量转换
- **自定义输出目录**：可指定输出位置，留空则保存到原图所在目录
- **质量可调**：图片质量 0-100 自由调节（适用于 JPG/WEBP 等有损格式）
- **智能边缘处理**：自动处理 JPEG 透明通道等特殊情况
- **后台执行**：转换任务在后台运行，界面不会卡顿

## 安装方法

* 通过不忙脚本盒子安装（推荐）  
  
  * 下载并安装 [不忙脚本盒子](https://www.bm-box.cn)  
  
  * 打开不忙脚本盒子 → **脚本市场** → 搜索 **「图片格式转换」**  
  
  * 点击「安装」  

* 手动运行（有编程基础用户）  
  
      1. 安装 imagemagick（imagemagick 命令需在 PATH 中可用）
      # 2. 配置python环境  
      uv venv  
      uv sync      # 3. 启动脚本  
      python main.py # 启动配置界面（无参数）
      python main.py <参数JSON路径>  # 带参数启动

✅ 推荐使用不忙脚本盒子安装、盒子会自动为脚本配置环境、依赖、imagemagick环境变量、并提供右键、快捷键执行脚本的能力

---

## 四：启动方式

通过不忙脚本盒子安装后，可通过以下方式使用「图片格式转换」功能：  

* 配置参数（首次使用或需修改配置时）  
  
  * 打开「不忙脚本盒子」  
  * 点击「图片格式转换」进入配置窗口  
  * 根据需求设置分割参数  
  * 点击「保存配置」  

* 执行音频格式转换（日常使用）  
  
  * 在文件管理器中选中视频文件  
  * 右键点击，选择「图片格式转换」  
  * 脚本自动按保存的配置执行格式转换  

* 快捷键操作  
  
  * 为脚本设置全局快捷键  
  * 选中视频后按下快捷键即可快速执行  

✅ 配置保存后永久生效，无需每次重复设置  

🔄 仅在需要更改参数时才需重新进入配置窗口
